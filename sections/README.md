# Manuscript Sections

This directory stores manuscript sections split out of the root `main.tex`.

## Current content

- `02--related_works.tex` - related-work section included from `main.tex`.

## Usage notes

- Keep section files focused on one manuscript component (for example, related work, methods, or discussion).
- Ensure section filenames are stable once referenced from `main.tex` to avoid broken includes.
- Preserve citation keys and labels when moving text between section files and the main manuscript.

## Review readiness

- Keep comments minimal and technical.
- Do not leave unresolved TODOs in section files before submission checkpoints.
- If a section is deprecated, archive its last state under `archive/` before removal.
