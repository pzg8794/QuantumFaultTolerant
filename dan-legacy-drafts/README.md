# Legacy Drafts

This directory keeps old planning drafts, one-pagers, and scratch notes out of the active manuscript root while preserving their history.

These files are not part of the active `main.tex` build. Treat them as historical context only.

## What belongs here

- Superseded proposal drafts.
- Preliminary structure outlines.
- Early positioning notes that informed later manuscript decisions.

## Handling rules

- Do not edit legacy drafts for active submission work.
- If a legacy argument is revived, copy the idea into active manuscript files instead of rewriting historical files.
- Keep filenames and timestamps stable for provenance.
