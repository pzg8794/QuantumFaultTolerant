# Historical Patches and Feedback Provenance

This top-level directory stores provenance material from manuscript cleanup passes:

- applied patch notes;
- consolidated Overleaf/reviewer feedback decisions;
- historical feedback queues;
- cleanup summaries.

This directory is intentionally outside `archive/` so that `archive/` can remain focused on manuscript source checkpoints only.

## Policy

- New provenance notes should go here, not under `archive/`.
- Keep manuscript checkpoints under `archive/manuscript-checkpoints/`.
- Leave `archive/legacy-drafts/` untouched unless the owner explicitly asks for changes.
- Avoid scattering many one-item feedback files in the repo root; consolidate feedback decisions into a single readable markdown file when possible.
