# Historical Patches and Feedback Provenance

This top-level directory stores provenance material from manuscript cleanup and review-processing passes.

It may include:

- applied patch notes;
- reviewer and Overleaf feedback decisions;
- historical feedback queues;
- older tracking files;
- cleanup summaries.

This directory is intentionally outside `archive/` so that `archive/` remains focused on manuscript source checkpoints only.

## Policy

- New provenance notes should go here, not under `archive/`.
- Manuscript source checkpoints should go under `archive/manuscript-checkpoints/`.
- Dan/legacy-owned planning drafts live at the top level in `dan-legacy-drafts/` and should not be edited unless Dan or the project owner explicitly asks.
- Local helper scripts and tools should remain local-only and are ignored by Git.
- Avoid scattering many one-item feedback files at the repository root; consolidate future feedback decisions into readable dated markdown files when possible.
