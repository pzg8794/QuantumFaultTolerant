# Tracking Archive

This directory keeps superseded tracker snapshots, deep-research reconstruction notes, and historical handoff material.

These files are retained for provenance only. New review decisions and paper-change records belong in `../PAPER-CHANGES-TRACKER.md`.

## Archive policy

- Add files here only when a tracker format is retired or replaced.
- Do not overwrite archived snapshots; append new snapshots with clear dates.
- Preserve original wording for auditability during reviewer-response reconstruction.

## Active source of truth

- Current decision and change logging: `../PAPER-CHANGES-TRACKER.md`.
- Historical-only reference: this archive folder.
