# Early Feedback Archive

This directory preserves the older feedback-tracker format from the retired top-level `tracker/` directory.

Use `../../PAPER-CHANGES-TRACKER.md` for current work.

## Purpose

- Keep the original early-review format intact for historical traceability.
- Provide context for how feedback handling evolved before the current tracker standard.

## Usage

- Read-only reference for provenance and timeline reconstruction.
- Do not add new reviewer actions in this format.
- Promote any still-open historical items into the active tracker if they become relevant again.
