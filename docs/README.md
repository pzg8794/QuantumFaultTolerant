# Supporting Documentation

This directory contains reusable reference material and external templates. The
active status and manuscript evidence are intentionally kept elsewhere so this
directory does not become a second tracking system.

## Repository Documentation Map

- `../updates/README.md` - concise advisor-facing progress and schedule.
- `../ICNP_VENUE_PREP/` - active audit, validation, feedback-resolution, and staging records.
- `../historical-patches/` - superseded feedback and tracker history.
- `../venues/` - venue-selection and submission-preparation references.
- `templates/` - external LaTeX templates and formatting references.

Keep manuscript edits in the owning `.tex` source or staging file. Do not add
progress trackers here; update the advisor page or the appropriate active
evidence record instead.
