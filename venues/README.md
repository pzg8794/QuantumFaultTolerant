# Venue Preparation

Venue-specific preparation material lives here.

## Active tracks

- `icnp_2026/` - active ICNP 2026 preparation notes, checklist, timeline, and source links.
- `journal/` - journal-submission fallback checklist and readiness notes.

## Workflow guidance

- Keep venue constraints (page limits, formatting, deadlines) in the corresponding venue folder.
- Store acceptance criteria, checklist progress, and submission artifacts by venue.
- Use dated notes for major scope decisions to preserve submission rationale.

## Reviewer-facing quality bar

- Each venue folder should make it clear what is current, what is historical, and what is pending.
- Avoid mixing journal and conference instructions in the same checklist file.
