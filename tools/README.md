# Paper Tools

This directory stores local utilities for maintaining paper artifacts.

- `annotate_reference_provenance.py` - reference provenance helper.
- `build_standardized_manuscript_tables.py` - standardized external-testbed table generator.
- `dedupe_reference_pdfs.py` - reference PDF duplicate checker.
- `import_testbed_pdfs.py` - external-testbed PDF import helper.
- `rename_reference_pdfs.py` - reference PDF naming helper.

Run Python tooling from the workspace `.quantum` environment unless a tool says otherwise.
