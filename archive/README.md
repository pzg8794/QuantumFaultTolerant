# Manuscript Archive

This directory stores source snapshots taken before major manuscript rewrites.

## Layout

- `manuscript-checkpoints/` - stable manuscript source snapshots.
- `legacy-drafts/` - old proposal drafts, one-pagers, notes, and unused image stubs.
- `historical-patches/` - patch files retained for provenance after their work was applied or superseded.

Archive entries are source snapshots only. LaTeX build artifacts and PDFs are intentionally ignored by Git.
