# ICNP Recent Top Papers Reference Folder

This directory is intended to hold recent ICNP paper PDFs and notes that can be used as style/reference examples while preparing the ICNP submission.

## Download status

PDF download from the assistant runtime was **not available** because public web/DNS access from the execution container failed for ICNP/IEEE hosts. Therefore, this directory currently contains a structured manifest and paper-note templates rather than downloaded PDFs.

Once PDFs are downloaded locally, place them in this directory using the filenames listed in `PAPER_DOWNLOAD_MANIFEST.md`.

## What counts as useful reference papers

Prioritize recent ICNP papers in or near these areas:

1. routing, path selection, or traffic engineering;
2. ML/AI-assisted networking;
3. robust/adversarial networking;
4. measurement and protocol evaluation;
5. quantum networking, if available in ICNP or adjacent networking venues.

## How to use this folder

For each selected paper:

1. download the PDF from the official ICNP program page, IEEE Xplore, ACM DL, or the authors' public copy;
2. save it under the filename listed in the manifest;
3. fill in a short note file using the template in `PAPER_NOTE_TEMPLATE.md`;
4. extract structural lessons relevant to our paper.

## Current recommended minimum set

Because direct PDF retrieval was blocked, the minimum set is represented as target categories rather than fabricated downloads:

- `01_recent_icnp_ml_for_networking.pdf` - recent ICNP paper using ML/learning for network control or protocol behavior.
- `02_recent_icnp_routing_or_traffic_engineering.pdf` - recent ICNP paper on routing/path control/traffic engineering.
- `03_recent_icnp_security_or_robustness.pdf` - recent ICNP paper on adversarial, secure, or robust networking.

If a recent ICNP quantum-networking paper is found, add it as:

- `04_recent_icnp_or_adjacent_quantum_networking.pdf`

## Important note

Do not cite these files directly in the manuscript unless they are actual related work. Their main purpose is to guide structure, tone, formatting, contribution framing, and evaluation presentation.
