## What to look for

When reviewing each example paper, pay special attention to:

- how quickly the paper states the protocol/networking problem;
- how it introduces ML or optimization, if present;
- how it justifies threat models or scenario choices;
- how many figures/tables are used in the main body;
- how it phrases contributions;
- how it handles artifacts, reproducibility, and limitations;
- how concise the related work section is.
